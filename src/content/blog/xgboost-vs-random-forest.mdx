XGBoost et Random Forest sont tous deux des ensembles d'arbres de décision, mais leur
fonctionnement diffère assez pour justifier un choix réfléchi plutôt qu'un réflexe.

## La différence fondamentale

**Random Forest** entraîne de nombreux arbres indépendamment, sur des sous-échantillons
aléatoires des données, puis moyenne leurs prédictions. Chaque arbre "vote" séparément.

**XGBoost** (gradient boosting) construit les arbres de façon séquentielle : chaque nouvel
arbre corrige les erreurs des arbres précédents. C'est une stratégie fondamentalement
différente — l'apprentissage est cumulatif, pas indépendant.

## Quand préférer Random Forest

- Le jeu de données est petit à moyen et le risque de surapprentissage (*overfitting*) est
  une préoccupation réelle
- Vous avez besoin d'un modèle robuste avec peu de réglage d'hyperparamètres
- L'entraînement doit être facilement parallélisable

## Quand préférer XGBoost

- La performance brute est prioritaire et vous pouvez investir du temps dans le réglage
  des hyperparamètres (taux d'apprentissage, profondeur, régularisation)
- Le jeu de données est de taille moyenne à grande
- Vous avez besoin de gérer nativement les valeurs manquantes

```python
import xgboost as xgb
from sklearn.ensemble import RandomForestClassifier

# Random Forest — robuste, peu de réglage
rf = RandomForestClassifier(n_estimators=200, max_depth=10)

# XGBoost — plus de contrôle, plus de performance potentielle
xgb_model = xgb.XGBClassifier(
    n_estimators=300,
    learning_rate=0.05,
    max_depth=6,
    reg_lambda=1.0,
)
```

## Le vrai conseil

Dans la pratique, tester les deux coûte peu de temps et donne une réponse empirique plus
fiable que n'importe quelle règle générale. La question à se poser n'est pas "lequel est
meilleur ?" mais "lequel est meilleur *pour ce jeu de données, avec ces contraintes* ?"
