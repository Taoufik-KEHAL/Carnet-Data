Deux types de dérive méritent d'être distingués, parce qu'ils se surveillent différemment. Le
data drift concerne la distribution des variables d'entrée — nouveaux profils de clients,
saisonnalité, évolution du marché — même si la relation entre variables et cible reste stable.
Le concept drift, lui, touche à cette relation elle-même : un profil identique n'a plus le
même comportement de risque qu'au moment de l'entraînement. Le second est plus dur à observer
directement, parce qu'il suppose de connaître la vraie valeur cible, souvent disponible avec
un gros délai.

## Le PSI, réutilisé du monde de la validation

Le Population Stability Index, déjà croisé en validation de modèle de risque, sert aussi en
monitoring continu :

```python
import numpy as np

def psi(distribution_reference, distribution_actuelle, bins=10):
    ref_hist, edges = np.histogram(distribution_reference, bins=bins)
    act_hist, _ = np.histogram(distribution_actuelle, bins=edges)

    ref_pct = ref_hist / len(distribution_reference) + 1e-6
    act_pct = act_hist / len(distribution_actuelle) + 1e-6

    return np.sum((act_pct - ref_pct) * np.log(act_pct / ref_pct))
```

En pratique, en dessous de 0,1 la population est considérée stable ; au-delà de 0,25, ça
mérite une investigation.

## Décider quand réentraîner

Réentraîner à date fixe, tous les mois par exemple, est simple mais aveugle — trop fréquent et
coûteux, ou trop lent face à une dérive rapide. Une approche plus solide combine trois signaux :
le PSI sur les features clés, la dégradation de performance mesurée dès que la vérité terrain
arrive, et le volume de prédictions hors distribution, souvent un signal précoce avant même que
la performance visible ne bouge.

Réentraîner automatiquement dès qu'un seuil est franchi, sans validation humaine, peut aggraver
les choses si la dérive vient d'une anomalie temporaire — un incident de collecte de données,
une panne en amont — plutôt que d'un vrai changement. Le monitoring devrait déclencher une
alerte et une investigation en premier, le réentraînement automatique ensuite, pas l'inverse.
