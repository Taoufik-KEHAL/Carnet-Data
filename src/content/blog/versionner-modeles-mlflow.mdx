Sur un projet de scoring crédit sur lequel j'ai travaillé, on avait fini par nommer les
fichiers de modèles `model_v2_final_vraiment_final.pkl`. Ça faisait sourire jusqu'au jour où
il a fallu expliquer à un auditeur quelle version avait produit une décision précise, six mois
plus tôt. On n'avait pas la réponse. MLflow existe pour ce genre de moment.

## Trois outils, pas un seul

MLflow regroupe plusieurs composants qu'on peut adopter séparément. Tracking enregistre les
paramètres, métriques et artefacts de chaque run d'entraînement dans une interface consultable.
Model Registry centralise les versions d'un modèle et leur statut — `Staging`, `Production`,
`Archived`. Projects packages un pipeline pour qu'il tourne à l'identique ailleurs. Dans la
pratique, la plupart des équipes n'ont besoin que des deux premiers.

## À quoi ressemble un run tracé

```python
import mlflow

mlflow.set_experiment("scoring-credit")

with mlflow.start_run():
    mlflow.log_params({"max_depth": 6, "learning_rate": 0.05})
    model = train(X_train, y_train)
    mlflow.log_metric("auc", evaluate(model, X_test, y_test))
    mlflow.sklearn.log_model(model, "modele", registered_model_name="scoring-credit")
```

Une fois ça en place, comparer deux runs devient un simple filtre dans l'UI, plus un tableur
partagé où chacun note ses essais à sa façon.

## Passer un modèle en production sans redéployer le code

Le Registry attribue un numéro de version à chaque modèle enregistré et permet de changer son
statut indépendamment du code qui l'appelle :

```python
from mlflow import MlflowClient

client = MlflowClient()
client.transition_model_version_stage(
    name="scoring-credit", version=7, stage="Production"
)
```

Le service qui consomme le modèle pointe vers `models:/scoring-credit/Production` en
permanence — la bascule se fait côté registre, sans toucher au code appelant.

Ce que MLflow ne fait pas : versionner les données. On peut retrouver quel modèle tourne, mais
pas forcément avec quelles données il a été entraîné, sauf à logger un hash en paramètre ou à
coupler ça avec un outil comme DVC. C'est un trou qu'on découvre en général au pire moment.
